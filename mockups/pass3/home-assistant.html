Each panel reads its own CSS variables and works out contrast and colour distance as it renders, so this is the spec, not a picture of it. "Jam Braun" under a swatch is the value the live theme uses today.

2 · Jam Cards

The card library

Cards at real phone size. Rockers, faders, keys and popups all work, and a change shows up on every copy of that card on the page. In the library each card is drawn as if it were alone on its screen, so each shows its own main button in orange; on a dashboard only one wins.

HA's own dialogs · keys verified

More-info, switch and confirm, themed by keys only

HA's built-in dialogs can't use Jam's rockers. These are drawn from HA's components as they are in release 20260930.5 (HA 2026.10): the big toggle takes state-<domain>-active-color, the small switch takes ha-switch-checked-*, buttons take the ha-color-primary-* ramp, and the light slider uses the light's own colour (HA nudges it for contrast). Pass 2's cream for the big toggle disappears on a Day card, so Day uses ink.
